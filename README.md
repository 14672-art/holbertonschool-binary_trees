# C - Binary Trees

This project is part of the Holberton School curriculum. It covers the concepts and implementations of Binary Tree data structures in C.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files compiled on Ubuntu 20.04 LTS using `gcc` with flags `-Wall -Wextra -Werror -pedantic -std=gnu89`
* Code formatted according to the **Betty** style.
